# Countryball Studio

Free online countryball maker with a light, simple interface: 265 real world flags, 4 shapes (ball, cube, triangle, brick), eyes, hats, speech bubbles and text, drawing, backgrounds, shine & shadow, random countryball, autosave, a small offline help bot, and PNG export up to 2400px.
Works offline and can be installed as an app (PWA).

- `index.html` – the app
- `flags.js` – all flag images
- Help bot "Bally": offline answers, edit `const BOT = [...]` to add more.
- Ad spot: edit `const ADS = {...}` at the top of the script in `index.html` (one small box only).
